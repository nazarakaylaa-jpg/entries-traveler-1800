One sentence, at most 200 characters, explaining the modern internet to someone arriving from 1800 — built only from things a person of that year already knows. The program writes it to `/output/entry.txt` on every run. Node 22, standard library only.

## The sentence

```
Picture a road of light joining every town on earth, where any letter arrives before the ink is dry and a library greater than any king ever owned opens the moment you ask for it.
```

179 characters. One road of light carries both halves of the internet: letters that arrive before the ink is dry (instant communication across the world) and a library greater than any king ever owned that opens the moment you ask (knowledge on demand). No word coined after 1800 — no internet, computer, screen, or wire — only road, light, town, letter, ink, library, king.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
